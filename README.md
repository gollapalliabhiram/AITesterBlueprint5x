# AI Tester Blueprint 5x

A learning repository for exploring AI-assisted software testing, reusable AI skills, test planning, and QA automation workflows.

## Objectives

- Explore reusable AI skills for software testing.
- Generate structured test plans from user stories.
- Identify requirement gaps, risks, and edge cases.
- Customize and validate skills using fictional test scenarios.
- Document learnings and testing examples.

## Repository Structure

- `Chapter_00_SKILL_Basics/` — advanced skill examples and learning material.
- `custom-skills/` — customized skills developed for this project.
- `SKILLS_CATALOG.md` — catalog of skills reviewed, adapted, and tested.

## Security

This repository must not contain personal access tokens, passwords, API keys, confidential company information, or proprietary source code.

## Status

Learning project in progress.
